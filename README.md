# Exam-Project-1
Exam Project 1 - Online Shop
ELLORY


# Description
This is the exam project 1. It is a responsive user interface integrated with the Noroff Online Shop API, allowing users to discover products, inspect comprehensive product information (title, description, price, rating, tags, and reviews), register and log into accounts, place items into a cart, and finalize purchases through a checkout flow.

# ELLORY 
ELLORY is the fictional client of the website.

At ELLORY we champion minimalist luxury: handcrafted scents, precision timepieces, elegant accessories, and premium electronics curated for the design‑minded. Discover small, intentional collections that blend craftsmanship with effortless wearability.
